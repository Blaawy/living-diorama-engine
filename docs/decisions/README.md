# Architecture Decision Records

This folder is the home for standalone Architecture Decision Records
(ADRs) as the project grows.

Currently, this project's ADRs are recorded inline within
`docs/architecture.md`:

- Section 12 -- *Aggregate District Simulation Before Individual Citizens*
- Section 13 -- *Post-MVP Architecture Decision: Memory Compaction*

Future decisions may be split out into individual numbered files in this
folder (for example `0001-title.md`) once there are enough of them that
a single inline section per decision stops being the easiest place to
find them. No such split has happened yet.
